# Learning Resource Request

## User Story

As a student, I want to post a request for learning
resources on a specific topic so that peers can recommend
suitable resources.

## Description

Students can post requests for learning resources related
to a specific topic. Other students can view the request
and recommend suitable learning materials.

## Expected Functionality

- Student enters a topic.
- Student describes the required resources.
- Student submits the request.
- Other students can view the request.
- Peers can recommend suitable resources.

## Acceptance Criteria

1. Student can enter a specific topic.
2. Student can describe the required learning resources.
3. Student can submit the request.
4. Other students can view the request.
5. Other students can recommend resources.
